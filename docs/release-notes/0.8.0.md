## Quill 0.8.0

**Separate Voices**
- More accurate. You may see one extra voice.
- If two voices are the same person, give both the same name and save. To undo, click **Not the Same Person**.

**Other changes**
- Opening a second transcript window no longer stops the first from saving names or closing.
- The "Meeting detected" prompt now stays until you respond or the call ends.
- Detects calls in more apps, including Zoom Phone, Webex, Aircall and 8x8 Work.
