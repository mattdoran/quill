## Quill 0.9.1

- Fixed: Quill could crash and vanish from the menu bar when AirPods or another audio device disconnected while recording. It now keeps recording, though a few seconds of audio can be lost each time.
- Fixed: a crash could save a recording as empty, with no transcript. Quill now recovers the audio and transcribes it when it next opens. Recordings already saved as empty aren't recovered.

**If Quill crashes**
- It reopens within seconds and usually carries on recording in the same meeting. "Recording resumed" says how much is missing, and the transcript marks the gap.
- A recording you Force Quit resumes too. To end it, click **Stop Recording**.
